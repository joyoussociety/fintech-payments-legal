# Fintech Payments

**Private QuickBooks Online Accounting Application**

Fintech Payments is an internal Windows desktop application for Quickie Maximin LLC, doing business as Joyous Society Wine Co.

The application is being developed to help authorized company personnel import customer payment information from Excel spreadsheets and apply payments to existing QuickBooks Online invoices.

## Connect to QuickBooks

QuickBooks authorization is initiated from the Fintech Payments Windows application using Intuit's secure authorization process.

The connection feature is currently under development and is not yet available.

## Disconnect from QuickBooks

Authorized users will be able to revoke the application's QuickBooks access through Intuit's account authorization controls.

The application's disconnect functionality is currently under development.
